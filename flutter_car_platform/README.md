# 🚗 منصة معارض السيارات | Flutter Car Showroom Platform

تطبيق متكامل لمنصة معارض سيارات تم بناؤه بأحدث تقنيات **Flutter** بنمط هيكلية نظيفة (**Clean Architecture & MVC**) مع **GetX** لإدارة الحالة والتنقل، و **Supabase** كقاعدة بيانات سحابية متزامنة في الوقت الفعلي (**Realtime Database & Storage**).

---

## ✨ المميزات الرئيسية

1. **دعم كامل للغتين العربية (RTL) والإنجليزية (LTR)** مع زر تبديل فوري.
2. **شاشة ترحيبية (Splash Screen)** بتأثيرات بصرية وشعار متحرك لمدة 3 ثوانٍ مع التحقق التلقائي من الجلسة.
3. **شاشة رئيسية ديناميكية**:
   - عرض قائمة المعارض المعتمدة.
   - كاروسيل متحرك سلس لأحدث السيارات في كل معرض مع الأسعار والتفاصيل.
4. **شاشة تفاصيل المعرض**:
   - تصفح سيارات المعرض مع محرك بحث فوري وتصفية بحسب الماركة، السعر، سنة الصنع، والحالة.
5. **شاشة إضافة سيارة للأفراد**:
   - رفع الصور مباشرة من الكاميرا أو المعرض (`image_picker`).
   - ضغط الصور تلقائياً قبل الرفع لتوفير الباندويث والسرعة.
   - إدخال كامل البيانات (الماركة، الموديل، السعر، المدينة، رقم الهاتف، والواتساب) ونشر الإعلان للمراجعة.
6. **دردشة فورية متزامنة (Supabase Realtime)**:
   - قائمة المحادثات النشطة.
   - غرفة محادثة 1-on-1 فورية مع شريط تفاصيل السيارة، رسائل جاهزة، وأزرار اتصال واتساب مباشر.
7. **لوحة تحكم الإدارة (Admin Dashboard)**:
   - تبويب اعتماد الإعلانات (قبول / رفض سيارات الأفراد المعلقة).
   - إدارة المعارض (إضافة / تعديل / حذف).
   - إدارة السيارات والمستخدمين مع مؤشرات وإحصائيات فورية.
8. **ملف CI/CD متكامل**:
   - سكريبت GitHub Actions (`.github/workflows/build.yml`) لبناء APK و AAB تلقائياً مع الكاشينج السريع.

- حساب مجاني على منصة [Supabase.com](https://supabase.com)

## 🚀 خطوات التشغيل خطوة بخطوة

### الخطوة 1: إعداد قاعدة بيانات Supabase

1. أنشئ مشروعاً جديداً في [Supabase](https://supabase.com).
2. افتح تبويب **SQL Editor** في لوحة تحكم Supabase.
3. انسخ محتوى الملف `supabase/schema.sql` من هذا المشروع والصقه في الـ SQL Editor واضغط **RUN**.
   - سيقوم بإنشاء الجداول (`users`, `showrooms`, `cars`, `messages`, `conversations`).
   - سيقوم بتفعيل سياسات الأمان RLS وحاويات التخزين `car-images` و `showroom-logos`.
   - سيقوم بتفعيل Supabase Realtime للرسائل.
   - سيقوم بإدراج بيانات تجريبية جاهزة للمعارض والسيارات.

### الخطوة 2: تكوين المتغيرات البيئية (.env)

1. في لوحة تحكم Supabase، اذهب إلى **Project Settings** -> **API**.
2. انسخ كل من:
   - `Project URL`
   - `anon public key`
3. قم بإنشاء ملف `.env` في المجلد الرئيسي للتطبيق (أو انسخ `.env.example` إلى `.env`):
```bash
cp .env.example .env
```
4. ضع القيم المنسوخة داخل ملف `.env`:
```env
SUPABASE_URL=https://your-project-ref.supabase.co
SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### الخطوة 3: تثبيت الحزم وتشغيل التطبيق

```bash
# 1. الدخول إلى مجلد المشروع
cd flutter_car_platform

# 2. تحميل الاعتماديات
flutter pub get

# 3. تشغيل التطبيق على المحاكي أو الجهاز الحقيقي
flutter run
```

## 🏗️ هيكلية المشروع (Project Architecture)

```
flutter_car_platform/
├── .github/
│   └── workflows/
│       └── build.yml               # CI/CD لبناء APK & AAB
├── assets/                         # الصور والأيقونات
├── lib/
│   ├── core/                       # الطبقة الأساسية
│   │   ├── config/                 # إعدادات Supabase والبيئة
│   │   ├── constants/              # الألوان، الثيمات، الثوابت
│   │   ├── routes/                 # مسارات وتوجيه GetX
│   │   ├── services/               # خدمات Supabase والتخزين
│   │   ├── translations/           # الترجمة ثنائية اللغة (عربي / إنجليزي)
│   │   └── widgets/                # المكونات المشتركة و Shimmer
│   ├── data/                       # طبقة البيانات
│   │   └── models/                 # نماذج البيانات (Car, Showroom, User, Message)
│   ├── presentation/               # طبقة العرض والواجهات (GetX)
│   │   ├── controllers/            # وحدات التحكم (Home, Showroom, Chat, Admin, etc.)
│   │   └── views/                  # شاشات التطبيق
│   │       ├── splash/             # الشاشة الترحيبية (3 ثوانٍ)
│   │       ├── home/               # الشاشة الرئيسية مع كاروسيل المعارض
│   │       ├── showroom/           # تفاصيل المعرض والتصفية
│   │       ├── car/                # إضافة سيارة وتفاصيل السيارة
│   │       ├── chat/               # قائمة المحادثات وغرفة الدردشة الفورية
│   │       └── admin/              # لوحة تحكم الإدارة الشاملة
│   └── main.dart                   # نقطة الدخول الرئيسية للتطبيق
├── supabase/
│   └── schema.sql                  # ملف SQL الكامل مع RLS و Realtime
├── pubspec.yaml                    # الحزم والاعتماديات
├── .env.example                    # مثال المتغيرات البيئية
└── README.md                       # التوثيق الشامل
```

## 🔒 أمان البيانات وسياسات RLS

- جميع الجداول مفعل بها **Row Level Security** بصرامة.
- الاستعلامات العامة تقتصر على السيارات المعتمدة (`status = 'active'`).
- إعلانات الأفراد تضاف بحالة `pending` حتى يعتمدها مدير النظام من لوحة التحكم.
- المحادثات والرسائل مشفرة الوصول ومحصورة على أطراف المحادثة ومديري النظام فقط.
